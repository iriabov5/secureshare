# SecureShare

## Возможности

Регистрация, сессионный вход и выход, загрузка, проверка целостности и скачивание собственных файлов. В интерфейсе доступны поиск, сортировка и управление активными сеансами. Максимум три сеанса на аккаунт; другой сеанс можно завершить на странице «Безопасность». Максимальный размер файла — 10 MiB.

## Компоненты

| Каталог / сервис | Назначение |
|---|---|
| backend/ | Kotlin, Spring Boot MVC, Spring Security, JPA, Flyway, AWS SDK |
| frontend/ | React, TypeScript, Vite; адаптивный интерфейс |
| PostgreSQL | Пользователи и метаданные файлов |
| S3 | Содержимое файлов; локально SeaweedFS |

Бэкенд из IDE и Vite запускаются отдельно. Полный bootJar включает React и запускается одним JVM-процессом. Сессии находятся в памяти процесса; после рестарта нужен повторный вход.

## Ограничения

Нет sharing, удаления файлов, MFA, throttling и восстановления пароля. Доступ к файлам ограничен владельцем. Новые объекты шифруются перед записью в S3. Существующие файлы можно зашифровать по одному из списка или массово служебной командой. Автоматической очистки незавершённых загрузок нет. Общей транзакции PostgreSQL/S3 нет.
